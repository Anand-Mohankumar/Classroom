To stream movies or play games we need fast connection. And to support these requirements of applications networks must be capable of transferring bits back and forth at a very high rate.
The rate is discussed in terms of bandwidth and throughput.

And the measurements are :
  • Thousands of bits per second (Kbps)
  • Millions of bits per second (Mbps)

Throughput

Amount of data that can be sent and received over a connection including any potential delays that might occur.
Units are the same as bandwidth but the Metrics are the different, because here it is not theoretical but more real world accurate data.
Throughput metrics  includes :
Ping : Time it takes for a small measure of data called "ping" to travel to the destination and back to your computer. Measured in milliseconds.
Download Speed : How many bits are downloaded per second.
Upload Speed : How many bits are uploader per second.
Throughput is influenced by :
  • The amount of data being sent and received over the connection
  • The types of data being transmitted
  • The latency created by the number of network devices encountered between source and destination
Latency refers to the amount of time, including delays, for data to travel from one given point to another.
Like we discussed in the previous sections there are multiple routers and devices involved in between our communications with devices in the networks. So we can observe a bad throughput if any device that enables our connection slows down.
So even if your router is capable of transmitting 1Tb of data per second, it doesn't mean that you will get 1Tb throughput on your connection.

Peer-to-Peer Networks

Client and server software usually run on separate computers,but it is possible for one computer to run both client and sever software at the same time.
In small businesses and homes, many computers function as sever and client on the network. This type of networks is called peer-to-peer (P2P) network.
The simplest version of this consists of two directly connected computers using a wired or wireless connection. Both computers are able to use the network to changed data and services acting as a server or client when necessary.
We can also create larger P2P network using switches and multiple PCs.
Main disadvantage of P2P is that the host can slow down if it acts as both client and server at the same time.
In large businesses, P2P is not ideal because there is a huge amount of traffic. Hence dedicated servers are implemented.
Advantages of P2P :
  • Easy to set up
  • Less complex
  • Lower cost because network devices and dedicated servers may not be required
  • Can be used for simple tasks such as transferring files and sharing printers
Disadvantages of P2P
  • No centralized administration
  • Not as secure
  • All devices may act as both clients and servers which can slow their performance

P2P Applications

This type of apps allow device to act as both client and server within the same communication.
In this model all clients are servers and all servers are a client.
P2P apps require end devices to have a User Interface and run background service.
Some P2P apps use hybrid system ie the resources is not centralized, but the index that tells them the location of resources is centralized.
In hybrid system each peer will access the index to get the location of resource stored on another peer.

LAN Components

LAN Components can be grouped into four main categories :
  • Hosts : Send and receive user traffic. Has an IP address. Generic name for most end-user devices.
  • Peripherals : Doesn't connect directly to the network. Instead relies on connected hosts to perform network operations. Camera, Scanner etc.
  • Network devices : Connect other devices. Mainly hosts. Controls and moves network traffic. Router, Switch etc.
  • Network media : Provide connections between the hosts and network devices. Can be wired (Copper, Fiber etc ) or Wireless
Hosts or end devices need an Network Interface Card (NIC) to be able to connect to the internet.
Some motherboards have them integrated. Otherwise we have to buy and connect an standalone card to the motherboard.
In addition to physically connecting the device to the intermediate device, you also have to configure them to make them able to connect to the internet.
The devices must have an IP address. And there are three parts to IP configuration which must be correct for the device to connect.
  1. IP address - This identifies the host on the network.
  2. Subnet mask - This is used to identify the network on which the host is connected.
  3. Default gateway - This identifies the networking device that the host uses to access the internet or another remote network.

Types of Media

Current age networks use mainly three types of media :
  • Metal wires within cables - Data is encoded into electrical impulses ( Copper ).
  • Glass or plastic fibers within cables (fiber-optic cable) - Data is encoded into pulses of light.
  • Wireless transmission - Data is encoded via modulation of specific frequencies of electromagnetic waves.

  • Fiber-optic cables use light to transmit data, making them immune to EMI and RFI.
  • They are commonly used in enterprise environments and large data centers.
  • They are constructed of glass or plastic, which do not conduct electricity.
  • Fiber-optic connections are a good choice for extending networks over long distances and in environments where interference is a problem.

Parts of the Fiber Optic cable and their functions :
  • Jacket: Protects the fiber against abrasion, moisture, and other contaminants. Composition can vary depending on the cable usage.
  • Strengthening Material: Surrounds the buffer and prevents the fiber cable from being stretched during installation. Often made of the same material used in bulletproof vests.
  • Buffer: Helps shield the core and cladding from damage.
  • Cladding: Made from slightly different chemicals than the core and acts like a mirror, reflecting light back into the core.
  • Core: The center of the optical fiber and the light transmission element. Typically made of silica or glass.
More details about Fiber :

  • Commonly used in corporations and to connect ISPs on the internet.

  • The format of the ping command is universally implemented and can be used on almost all network-attached devices

Mac Address

A MAC address is the unique identifier that is assigned by the manufacturer to a piece of network hardware (like a wireless card or an ethernet card). MAC stands for Media Access Control, and each identifier is intended to be unique to a particular device.

Mac Address in-depth
  • Communication requires identification of source and destination.
  • In human communication, names are used to identify source and destination.
  • On Ethernet networks, physical addresses are assigned to each host to identify it on the network.
  • Every Ethernet network interface has a unique Media Access Control (MAC) address assigned to it at manufacturing.
  • The MAC address serves as the identification for each source and destination host on the network.
MAC addresses are 48 bits long and written in hexadecimal notation
They are made of 2 parts:
OUI (Organizationally Unique Identifier), the first 3 bytes, representing the manufacturer
The unique ID for the interface, the remaining 3 bytes
Vendors must register with IEEE to be assigned an OUI
Each OUI must have unique values in the last 3 bytes for all addresses starting with that OUI.
Switches operates on Mac Address basis. Which means the brain that i referred to earlier basically processes Mac address to make decisions on where to forward incoming data to. The information about connected devices in a switch is stored in a memory called Cam (Content Addressable Memory) Table. chunk of Information that are going through switches are called Frames. And frames with additional information including IP address attached are called Packets.

Routers

Let's tackle the basic question  of why connecting two switches together does not work. And the answer to this question can be used to understand the importance of routers in networking.
Before we jump straight into that, let me go through a mystery topic that we didn't discuss about Switches.
Its called ARP ( ie Address Resolution Protocol ).
Switch is a layer two device, so how does it know which user/device has which IP address? they cannot read IP addresses right?
And that is where ARP comes in,
What it means is basically the process where the Switch broadcast to all the connected devices a message ( more like an announcement  asking " Hello everyone, I have a message for an IP address 1.1.1.4 , And I'm looking for its owner. If its you, kindly let me know " ).
After the message reaches all the devices, they will all verify the IP address that was assigned to them. And whomever has the requested IP address attached to them will reply back ( " Hey dude, that IP address belongs to me, what's the message? " )
And as the Next step, the switch will send the message to the responder.
When PC needs to communicate to an unknown device, the start with an ARP Request which basically means a request to initialize ARP.

IP Configuration - Static Vs Dynamic

IP of an end device can be configured manually (Static) where the device is allowed to use only the IP address and other information which we have manually entered while configuring the device.
OR
It can be made Dynamic where the IP a device gets is randomly assigned by someone else.
This someone else is called a DHCP Server. where DHCP means Dynamic Host Configuration Protocol.When a device tries to connect to the internet, if the device is configured to follow DHCP, what happens is :
  1. The device connects to the network and broadcasts a message called DHCP Discover to find if there is a DHCP server on the network.
  2. The DHCP server receives the request and gives the device an IP address, subnet mask, default gateway and dns server info. This information is sent to device in a DHCP Offer.
  3. The device receives the DHCP Offer and sends a DHCP Request message to the DHCP server to confirm the IP address.
  4. The DHCP server receives the DHCP Request and confirms the IP address assignment by sending a DHCP Acknowledge (DHCP ACK) message to the device.
  5. The device receives the DHCP ACK and configures itself with the IP address, subnet mask, default gateway, and DNS server information.
  6. The DHCP server assigns a lease time for the IP address, which is the amount of time the IP address assignment will remain valid. After the lease time expires, the device must request a new IP address assignment.
  7. The device continues to use the assigned IP address to communicate with other devices on the network until the lease time expires, at which point the process starts again.

OSI Model VS TCP/IP Model

  • OSI Model provides a general understanding of networking functions, while TCP/IP model focuses on the specific protocols used for internet communication.

  • The transport layer of both models is the same, but the network access layer and the application layer of TCP/IP are divided into further functions in the OSI model.
  • OSI Layer 3 maps to TCP/IP internet layer and describes protocols for addressing and routing messages.
  • OSI Layer 4 maps to TCP/IP transport layer and provides ordered and reliable delivery of data.
  • TCP/IP application layer includes multiple protocols for specific end user applications.
  • OSI Layers 5, 6, and 7 used as references for application software developers.
  • Both models are commonly used for referring to protocols used in different layers, OSI is often used to discuss lower layers (data link and physical).

Transport Layer
This layer determines how to send data from the device to the other side.
Most popular options are :
  • Transfer Control Protocol (TCP)
    • Ensures every frame sent by the user reaches the destination.
    • Reliable
    • Not Fast
    • If YouTube for example sent you an html file of its home page, right after sending it, YouTube will ask " Did you get it? " to the receiver. If there is no response from our side, it will send the same thing again and again until your system finally says " Got it, send the next one ".
    • Also before any data transfer is made, the TCP will start with a process called Three-way handshake. Basically a way for the two to confirm that their communication is working.
      • How it works is  :
        • Johnys  system will initially send a synchronize request (SYN) similar to asking " Hey YouTube, are you there? ".
        • To which Youtube will  respond with a Synchronize Acknowledgement (SYN-ACK) similar to saying " Yes dude, I'm here. "
        • Then, Johnys system will reply back with an Acknowledgement (ACK)  and this is an alternative to saying " Ok dude, it seems our we are ready to communicate ".
    • After the handshake is successful, the devices can start sending frames with each other.
  • User Datagram Protocol (UDP)
    • No verifications. And does not care if the packet reaches the destination
    • Will keep on sending data without even bothering to check if the receiver is getting anything.
    • Not Reliable but real-time
    • Fast

Encapsulation

Sending a message over a computer network is like sending a letter. Just like a letter is put into an envelope, a message is put into a frame. This process is called encapsulation. The frame has the addresses of the sender and receiver, and the contents of the message. The frame ensures that the message is delivered and understood by the recipient. If the message is not correctly formatted, it will not be successfully delivered or processed by the receiver. This process of putting a message in a frame is important for computer networks to work properly.

Ethernet Frame

The Ethernet protocol standards are rules that define how computers communicate with each other on a network. Messages sent on an Ethernet network are formatted into frames according to these standards. Frames are like envelopes that contain information like the sender and recipient addresses. The format of Ethernet frames includes information like the MAC addresses, a preamble for timing, and a check sequence to detect errors. Ethernet frames have a maximum size of 1518 bytes and a minimum size of 64 bytes. The standards also define how the bits in the frames are transmitted over the network, either as electrical or light impulses. Following these standards is important for successful communication between computers on an Ethernet network.

Benefits of a Hierarchical Design

  • Hierarchical design is a method of organizing networks into layers of smaller, more manageable groups.
  • Hierarchical design improves network efficiency, function, speed, and scalability.
  • The three layers of hierarchical design are access, distribution, and core.
  • Access layer connects hosts to local networks.
  • Distribution layer interconnects local networks.
  • Core layer provides high-speed connection between distribution devices.
  • IP is the logical addressing scheme that identifies host location. It includes IPv4 and IPv6.

Access Layer Devices

  • The access layer is the first level of the network, where people gain access to other hosts and shared files and printers.
  • It is the part of the network that connects hosts to the wired Ethernet network.
  • Networking devices are used to connect hosts with each other and to provide access to network services.
  • In the access layer, each host is connected to a networking device, unlike a simple network where two hosts are connected by a single cable.
  • Ethernet cables are used to connect each host directly to the access layer networking device.
  • The cables are manufactured to meet specific Ethernet standards.
  • There are several types of networking devices used at the access layer, including Ethernet switches.

Ethernet Hubs

  • Original Ethernet networks used a single cable to connect all hosts, but as networks grew, this became impractical
  • Ethernet hubs were developed as a way to connect multiple devices to the network
  • Hubs contain multiple ports for connecting hosts, but are simple devices that cannot decode messages or determine which host should receive them
  • Hubs regenerate or repeat messages to all ports, so all hosts attached to the hub share the bandwidth and receive the message
  • Only the host specified in the destination address processes the message and responds to the sender
  • Collisions can occur when two or more hosts attempt to send a message at the same time, causing the messages to collide and become unreadable
  • Hubs are now considered obsolete and have been replaced by Ethernet switches, which can handle multiple messages at the same time and prevent collisions

Ethernet Switches

  • Ethernet switches are used in the access layer of a network
  • They decode frames to read the physical (MAC) address portion of messages
  • A table on the switch, called a MAC address table, contains a list of all active ports and host MAC addresses attached to them
  • When a message is sent, the switch checks the destination MAC address in the table
  • If the address is in the table, the switch builds a temporary connection between the source and destination ports, providing a dedicated channel for communication
  • Other hosts connected to the switch do not share the bandwidth on this channel and do not receive messages not addressed to them
  • A new circuit is built for every new conversation between hosts, allowing multiple conversations to take place without collisions
  • Ethernet switches allow sending and receiving frames over the same Ethernet cable simultaneously, improving network performance by eliminating collisions.

Mac Address Table

  • Switches use a MAC address table to create a temporary connection between the source and destination ports for every new conversation between hosts.
  • When a switch receives a frame addressed to a new host that is not in the MAC address table, it uses flooding to forward the message to all attached hosts except the sender.
  • Each host compares the destination MAC address in the message to its own MAC address, but only the host with the correct destination address processes the message and responds to the sender.
  • The MAC address table is built by examining the source MAC address of each frame sent between hosts, and the table is dynamically updated each time a new source MAC address is read by the switch.
  • When a new host sends a message or responds to a flooded message, the switch immediately learns its MAC address and the port to which it is connected.
  • The MAC address table allows switches to quickly learn the MAC addresses of all attached hosts, enabling them to build individual circuits between hosts for more efficient communication.

Broadcast Containment

What are Broadcasts?

  • Broadcast messages are used when a host needs to send messages to all other hosts on the local network.
  • Broadcast messages can be used to find information without knowing exactly which host has the information, or to provide information to all other hosts in a timely manner.
  • A message can only contain one destination MAC address, so broadcast messages are sent to a unique MAC address that is recognized by all hosts.
  • The broadcast MAC address is a 48-bit address made up of all ones.
  • MAC addresses are usually represented in hexadecimal notation, and the broadcast MAC address in hexadecimal notation is FFFF.FFFF.FFFF.
  • Each F in the hexadecimal notation represents four ones in the binary address.

Broadcast Domains

  • A host processes a broadcast message as though it was addressed to it
  • Switches forward a broadcast message to every connected host within the same local network
  • A local area network with one or more Ethernet switches is referred to as a broadcast domain
  • Excessive broadcast traffic can occur if too many hosts are connected to the same broadcast domain
  • The number of hosts and network traffic is limited by the capabilities of the switches
  • Dividing one local network into multiple networks or broadcast domains is necessary to improve performance
  • Routers are used to divide the network into multiple broadcast domains

Access Layer Communication

  • On a local Ethernet network, NIC only accepts frames with destination address as broadcast MAC address or the MAC address of the NIC itself.
  • Network applications rely on logical destination IP address to identify the location of servers and clients.
  • If a sending host only has logical IP address of destination host, it needs to determine the destination MAC address to place within the frame.
  • IPv4 uses Address Resolution Protocol (ARP) to discover MAC address of any host on same local network.
  • IPv6 uses a similar method called Neighbor Discovery.

Address Resolution Protocol (ARP)

  • ARP is an IPv4 protocol used to discover the MAC address of a host on the local network when only the IPv4 address is known.
  • ARP uses a three-step process to discover and store the MAC address of the host on the local network.
  • The first step is the sending host creating and sending a frame addressed to a broadcast MAC address, which contains a message with the IPv4 address of the intended destination host.
  • In the second step, each host on the network receives the broadcast frame and compares the IPv4 address inside the message with its configured IPv4 address.
  • The host with the matching IPv4 address sends its MAC address back to the original sending host.
  • In the third step, the sending host receives the message and stores the MAC address and IPv4 address information in a table called an ARP table.
  • Once the sending host has the MAC address of the destination host in its ARP table, it can send frames directly to the destination without doing an ARP request.
  • All hosts in the local IPv4 network must be in the same broadcast domain for ARP messages to rely on broadcast frames to deliver the requests.

Routing Between Networks

Criteria for Dividing the Local Network

  • Networks may need to be divided based on various criteria as they grow
  • The distribution layer connects independent local networks and controls traffic between them
  • The distribution layer ensures that local traffic stays local and only forwards traffic destined for other networks
  • The distribution layer may filter incoming and outgoing traffic for security and traffic management purposes
  • Devices in the distribution layer are meant to interconnect networks, not individual hosts
  • Individual hosts are connected to the network via access layer devices such as switches, which are connected to each other via a distribution layer device such as a router.
There are many ways to divide networks based on different criteria:
  • Broadcast containment
  • Security requirements
  • Physical locations
  • Logical grouping

Broadcast Containment
Routers in the distribution layer can limit broadcasts to the local network where they need to be heard. Although broadcasts are necessary, too many hosts connected on the same local network can generate excessive broadcast traffic and slow down the network.
Security
Routers in the distribution layer can separate and protect certain groups of computers where confidential information resides. Routers can also hide the addresses of internal computers from the outside world to help prevent attacks, and control who can get into or out of the local network.
Locations
Routers in the distribution layer can be used to interconnect local networks at various locations of an organization that are geographically separated
Logical Grouping
Routers in the distribution layer can be used to logically group users, such as departments within a company, who have common needs or for access to resources.

The need for routing

  • Remote hosts are devices beyond the local network segment
  • Routing is the process of identifying the best path to a destination
  • A router connects multiple Layer 3, IP networks
  • Routers make forwarding decisions based on the Layer 3 IP address
  • The packet format contains the IP addresses of the destination and source hosts, as well as the message data being sent between them
  • Routers read the network portion of the destination IP address to find which network is the best way to forward the message
  • Anytime the network portion of the IP addresses of the source and destination hosts do not match, a router must be used to forward the message
  • Routers receive the message, de-encapsulate the Ethernet frame, read the destination IP address, determine where to forward the message, re-encapsulate the packet into a new frame, and forwards the frame to its destination.
