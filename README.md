# Classroom

Classroom is a website for learning technical skills. It brings together training materials, career roadmaps, homelab setups, and hands-on projects. Each notebook focuses on a topic, skill, or project.

## Notebooks

- [AI Career Roadmap](notebooks/aicareerroadmap/) — An illustrated guide to six AI career paths, with skills to build and resources for getting started.
- [Linux Fundamentals (HTB)](notebooks/linux-fundamentals/) — Lecture notes on Linux, from the filesystem and terminal to system administration and shell scripting.
- [Networking Fundamentals](notebooks/networking-fundamentals/) — Lecture notes on local networks, network devices, protocols, Ethernet, and routing.

## Creating notebooks

The [Notebook Authoring Guide](docs/notebook-authoring.md) covers creating a notebook, converting an existing article or website, making papercraft illustrations, and adding the finished notebook to Classroom.
