# Classroom repository instructions

Classroom is a static site. Each notebook is a standalone page under `notebooks/<slug>/`.

- Read the [Notebook Authoring Guide](docs/notebook-authoring.md) before creating a notebook or converting a website, article, or local document.
- Start from [Linux Fundamentals](notebooks/linux-fundamentals/index.html) for linear reading, [Networking Fundamentals](notebooks/networking-fundamentals/index.html) for table-heavy or illustrated material, or [AI Career Roadmap](notebooks/aicareerroadmap/index.html) for a roadmap with an interactive map.
- Preserve the approved source's wording, structure, figures, and credits. Exclude personal or sensitive information from public files, metadata, examples, and images. Flag any resulting omission to the requester outside the notebook.
- Keep new notebook-specific assets and changes in its folder. Check affected notebooks before changing [shared papercraft assets](notebooks/papercraft/).
- Register the notebook on the [classroom whiteboard and no-script shelf](index.html) and in the [README](README.md). Match the classroom desk book's title and cover color to the notebook.
